# اتحاد طلاب مصر القديمة

منصة تفاعلية لاتحادات الطلاب، تتضمن صفحات الأخبار والمكاتب الطلابية والأنشطة والإرشادات، مع حركات بصرية متجاوبة.

## تشغيل الموقع محليًا

يتطلب Node.js. من داخل مجلد المشروع شغّل:

```bash
npm install
npm run dev
```

## الرفع إلى GitHub

ارفع محتويات هذا المجلد كما هي. لا ترفع مجلد `node_modules` أو ملفات البيئة الخاصة.
